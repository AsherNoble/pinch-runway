## Goal

Turn deterministic engine outputs into concrete, consequence-led ping payloads.

**Priority:** P0 · **Lane:** engine · **Size:** S
**Depends on:** ENG-03

## Acceptance criteria

- [ ] Produce structured ping data: text, amount, consequence, CTA, and action target.
- [ ] Match the supplied tone: specific number and real consequence, never a generic budgeting nudge.
- [ ] Clearly distinguish “sit tight” from “chase now.”
- [ ] Avoid claims about bank balances, funds availability, or regulated financial advice.
- [ ] Include testable copy examples for all four forecast states.
