## Goal

Persist only the user-declared living draw and lumpy upcoming expenses in the
selected hosted database.

**Priority:** P1 · **Lane:** frontend · **Size:** M
**Depends on:** RUN-01, RUN-02

## Acceptance criteria

- [ ] Persist only user-entered weekly draw and lumpy items in the selected database.
- [ ] Weekly draw has no due date; lumpy items require amount/date and allow an optional note.
- [ ] Schema/API contains no bank transaction, financial-account, email, calendar, or investment concept.
- [ ] Server validates integer cents, valid dates, and ownership.
- [ ] The database choice and migrations are documented.

## Scope note

This is a persistence task, not authorization to add open banking/CDR or other
data sources.
